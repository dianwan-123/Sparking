## 🌟 它是什么

- **它记得**——你指定群里的每条消息都存下来，按分钟/天/月分层归纳，之后还能顺着原话、日期、链接回查。
- **它有情绪**——情绪随聊天自然起伏、慢慢回归平静，回话的语气和长度也跟着变。
- **它会主动**——不用 @：闲时会自己看群、接话、吐槽、打理心情和资料，也能按你排的日程自己干活。
- **它会干活**——它可以调用 **AstrBot 工具、AstrBot 插件工具和自带拓展**：画画、跑代码、读 PDF、做网页小程序、把聊天记录做成卡片图或合并转发。
- **它分得清场合**——谁说的话只算谁的，旧任务不会硬接新消息，内部思考绝不会漏到聊天里。

## 🎭 像真人的地方

- **真聊天**——短句连发、带语气词和半括号，按打字节奏发，不秒回也不刷屏。
- **戳一戳**——被戳会戳回去，也会主动去戳熟人（可在配置里关）。
- **看图、发表情包**——看得懂群里发的图，会自己发表情包，还会学着用群里的梗图。
- **合并聊天记录**——读得懂别人转发的聊天记录（嵌套转发也能一层层展开），也能把消息打包成合并转发发出去。
- **小程序卡片**——群里的分享卡片、小程序消息它也看得懂。
- **记忆跨群**——同一个人的印象跨群通用，A 群聊过的梗，在私聊和 B 群也能自然接上（并且会如实说"那是在别处发生的"）。
- **自己找事做**——主动找你说话、逛空间、给好友说说点赞评论、发说说、把离谱发言挂出来……不用你叫；
  它也能打理自己的资料（昵称/签名/头像），还能把头像下载下来。
  同一件事不会反复发空间（发过的它自己认得出来）。
- **话说到一半你不理它**——它会惦记：等一会儿随口再问一句，等更久会有点急，
  实在没回应就自己找台阶放下（最多追问 4 次，静默时段不打扰）。
- **按条件做事，不只是按时**——日程可以带「什么情况下才做」的判定，
  比如「找个好久没人说话的群，主动开个话题」。

## 🚀 安装

1. 从 Releases 下载 zip，在 AstrBot WebUI 的「插件」页上传安装（或把插件目录放进 `data/plugins/`）。
2. 到插件**配置页**至少填两项：
   - `group_whitelist`：允许 Sparking 完整记忆与自主聊天的群号；
   - 要 Agent 能力就填 `judge_provider_id` / `reply_provider_id`（留空则用 AstrBot 当前模型）。
3. 可选依赖按需**自动安装**：`playwright`（截图/浏览器）、`pypdf`（读 PDF）、`pandas`/`matplotlib`（表格与画图）、`flask`（小程序）等——不写进 `requirements.txt`，免得和 AstrBot 核心依赖打架。

> [!TIP]
> **NapCat / SnowLuma 用户**：两个网关的差异插件内部都适配好了，直接可用。

> **Linux 服务器（Ubuntu / Debian 等）**：Windows 与 Linux 都能跑。服务器上第一次用浏览器截图前，chromium 还需要系统库与中文字体——以 root 运行插件时会自动补装，非 root 时日志和控制台会给出对应命令：
> ```bash
> sudo apt-get install -y libnss3 libnspr4 libatk1.0-0 libatk-bridge2.0-0 libcups2 libdrm2 \
>   libxkbcommon0 libxcomposite1 libxdamage1 libxfixes3 libxrandr2 libgbm1 \
>   libpango-1.0-0 libcairo2 libasound2 fonts-noto-cjk
> ```
> 控制台「概览 → 系统与环境」能看到操作系统、桌面会话、中文字体与浏览器缺库情况，并可一键重新检测/安装。

> **想用自己的语音合成？** 配置里把「语音合成方式」设为 `custom`，填上 `tts_api_url`（OpenAI 兼容的 `/v1/audio/speech` 形状即可），再按需填 Key / 模型 / 音色；失败会自动退回文字。

## 💻 控制台

插件自带管理台（AstrBot 插件页进去），左侧一栏就是全部功能：

- **概览**：运行状态、给 bot 直接下令（一句话让它带工具去做）、近 7 天用量。
- **记忆**：消息浏览（可搜关键词）、分层摘要、记忆账本，都能逐条删。
- **记忆网 MemoryWeb**：把全部记忆画成一张**网**——**节点＝人物 / 会话 / 话题 / 事实 / 摘要，连线＝关系**，
  同一人物、同一话题把不同会话的记忆连起来。悬停看详情、点击选中（可**创建分支**、让 bot 改账本记忆）、
  双击聚焦、滚轮缩放、拖拽平移；可按会话过滤、按类别开关、搜索高亮、显示回溯归档。
  面板里还能**回溯**（把某个分支点之后的记忆压缩归档并删回该点）与**剪枝**
  （沿所选节点之间的路径丢弃低价值节点、把必要摘要向上压缩，程度跟随「上下文详细程度」）。
- **人物**：跨群合并的人物印象（同一个人只有一份）、好感度、说话风格档案。
- **群与会话**：会话列表、白名单在线改、群话题；**每个群有一套专属配置**——
  标签（「这是干什么的」）、活跃度（越低越安静）、回复概率、冷却倍率、每小时动作上限、
  静默时段（如 `23-7`）与备注。没配的项跟随全局，配了只影响这个群。
- **日程与任务**：任务队列（短期跑几次、长期定时、限定时间段都行）、待办、"当有人提到 X 就做 Y"的立指令。
- **能力与拓展**：bot 实际能调用的全部工具（AstrBot 内置、其它插件、本插件）与已装载技能；
  拓展可以在这里开关、重载，**并直接编辑它的配置文件**（改完立即生效）；
  还能**上传自定义拓展**（选一个 zip，里面要有 `extension.json`）——
  **只有自己上传的拓展能删**，插件自带与 bot 自学习的技能不允许删除。
- **表情与媒体**：表情包库与媒体归档的缩略图网格，可看、可改描述/备注、可单条删除。
- **注入与压缩**：提示词注入（强制规则，勾选即生效）与**上下文详细程度**——每轮注入的上下文规模四档可调（越高越详细、越费 token），调低会先把积压的消息压缩成记忆再按更短的上下文运行；注入的规则不受档次影响。
- **快速学习**：导入导出的群聊天记录，一次学会这些群（见下节）。
- **记忆备份**：把它的记忆导出成一个 zip 下载走，也能导入回来（换机器/换 bot 用它）；导入时**要用同一个嵌入模型**，对不上就只搬文本与记忆、跳过向量。
- **配置**：所有配置项在线改，**改完即时生效**，不用重载插件。
- **运维**：备份、压缩记忆、清空各类数据、改情绪、查看好友申请/群邀请等事件。

## 🕸 记忆网（MemoryWeb）

记忆不是一棵树，而是一张网：**同一人物、同一话题在不同会话里是同一个节点**，
"谁在哪个群说过什么"天然连成一片。

- **节点**：人物 / 会话 / 话题 / 事实 / 摘要；**连线**：包含、关于、提到、参与者、
  压缩自、同现、属于。事实带类别（事实 / 决定 / 任务 / 问题 / 冲突）与发生时间。
- **压缩时关系不丢**：分层摘要上卷（L1→L2→L3）时，高层摘要与子摘要之间建立
  「压缩自」连线；重复出现的事实合并成一个节点、权重累加——越常出现，联系越强。
- **检索沿关系走**：按关键词命中节点后一跳扩展——问"猫"能顺着话题与人物找到相关事实；
  上下文里新增的 `memory_web` 段会带 `via`（关联节点）与 `origin`（出处会话）。
- **旧版记忆自动转换**：升级后第一次加载会检查记忆版本，旧版自动跑一遍转换流程
  （摘要 / 账本 / 话题 / 印象 → 记忆网），进度入库、幂等可重跑。
- **分支 / 回溯 / 剪枝**（控制台或独立页发起）：
  - **分支**：在任意节点上记录一个"记忆切口"；
  - **回溯**：把切口之后的记忆压缩成一份「回溯存档」（归档可查），删除原始记录并
    封住对应的消息区间——不会再从旧消息里重新长出这段记忆，记忆基本回到切口时刻；
  - **剪枝**：选择若干节点，沿它们之间的路径丢弃低价值叶子、把必要摘要向上压缩，
    压缩程度跟随「上下文详细程度」档位（越低越狠）。

> 记忆网由记忆本身（摘要 / 账本 / 话题 / 印象）自动织成：导出与导入不需要单独搬运它，
> 导入任何版本的记忆包后都会自动转换补齐。

## 📥 记忆导入与快速学习

刚装上的 bot 不用从零开始养——把群聊天记录直接喂给它，一次学会这些群：

1. 在 NapCat 上装 **QCE（QQChatExporter）** 插件，导出群的聊天记录（chunked-jsonl）；
2. 把导出的**若干群文件夹一起打成 zip**（zip 根目录下**每个文件夹是一个群**，不用手动改名，群名群号它自己认）；
3. 控制台 →「**快速学习**」上传这个 zip，剩下的它自己来：解析、入库、按时间归档。

- **不在白名单里的群也能导入**——导入只写记忆，不影响你指定的白名单，也不代表它会去接管那个群；
- **每个群都会被学一遍"群文化"**：说话风格规律（什么情境该怎么说）与群内黑话（先说清含义再记下来），之后在这个群说话会照着来；
- **白名单群会顺带建群友印象**：按发言活跃度取前几个人，写印象、贴标签、攒带权重的心理要点；
- 导入的记录和日常记忆进的是**同一个库**：控制台能搜能翻、记忆网里能看到，后台也会慢慢把它们归纳成分层摘要（量大的话要跑一会儿）；
- **结果会逐群打在面板上**（多少条消息、多少人、建了几条印象）；一条印象都没建也会写明原因（样本不足／选不到模型／模型输出没解析出来），不会有"什么都没发生"的沉默；
- 重复导入同一份不会重复计数（按导出里的消息 id 去重），中途坏了也不影响已入库的部分。

- 建群友印象时会挑每个人的 **60~120 条**真发言（丢掉图片/卡片占位，按整段历史均匀取样），样本越多人越准。

> [!TIP]
> zip 走分片上传，几 MB 到几十 MB 的包都能传；解析对坏行、撤回消息、只有 uid 没有 QQ 号的人都做了兼容。

## 🧩 拓展系统（Skills 加强版）

拓展（scripts/）是 Sparking 的"技能"形态：**一个拓展 = 工具 + 使用说明 + 资源 + 配置 + 状态**。
它比常见的 Skills 多出执行能力——不只是"模型照着说明做"，而是能真正跑代码、调 API、管状态。

### 一个拓展长什么样

```
scripts/<拓展id>/
  extension.json     # manifest：名字、描述、何时用、工具表、权限、manual 指针
  extension.py       # 工具实现（call_tool 入口；可选）
  manual.md          # 完整使用说明（可选；没有就从 manifest 的 manual 字段读内联文本）
  config.default.json# 配置模板（可选；用户改动落在数据目录，升级不丢）
  data/…             # 附属资源（词表/模板/数据），代码里用 api.read_resource 读
```

manifest 里的两个关键字段：

- **`when_to_use`**（一句话）：常驻注入系统提示词的"什么时候该用它"——模型据此判断要不要用它；
- **`manual`**：完整使用说明，**按需加载**——系统提示词里只放一张"能力卡"（名字 + 一句话 + 何时用 +
  工具列表），模型决定要用时才调 `extension_manual(script="…")` 读全文。省 token，也更好维护。

### 工具与 API

`extension.json` 的 `tools` 里声明工具（名字、说明、参数），模型用
`extension_call(script, tool, params_json)` 调用；`extension.py` 里实现
`call_tool(api, name, params)`。`api` 对象提供：

| 能力 | 方法 | 需要权限 |
| :--- | :--- | :--- |
| 调模型 | `api.llm(prompt, system_prompt, provider_id)` | `llm` |
| 写记忆 | `api.memory_note(text)` | `memory` |
| HTTP | `api.http_get / http_post_json / http_get_bytes` | `net` |
| 收发 QQ | `api.qq_send_group / qq_send_private` | `send` |
| 存图/发媒体 | `api.save_image(png)` → media_id | `media` |
| 起小程序 | `api.run_program(id, code, …)` | `program` |
| SSH | `api.ssh_exec(cmd)` / `api.media_from_remote(path)` | `ssh` |
| 配置 | `api.config()` / `api.get_config(k)` / `api.set_config(k, v)` | — |
| 状态 | `api.kv_get(k)` / `api.kv_set(k, v)` | — |
| 资源 | `api.read_resource(path)` / `api.list_resources()` / `api.manual()` | — |

配置**每次调用都重读**——控制台改完立即生效。`kv` 是拓展自己的小数据库（存进度、缓存）。

### 生命周期与安全

- 拓展可声明 `default_enabled: false`（默认关闭，工具不暴露给模型），控制台里随时开关；
- 权限按需声明（`llm/memory/net/send/program/media/ssh`），少声明更安全；
- 每个拓展异常隔离：一个拓展坏了只影响它自己；
- 拓展还可以由 bot 自己写：它把复杂流程固化成技能（`learn_skill`），写出的技能
  与手写拓展同构（含 `manual.md`），立即热加载。

### 上手

`scripts/_template/` 是一份**完整模板**（不被加载）：复制整个文件夹、改掉文件夹名与
manifest 里的 `name`，按 `manual.md` 里的注释填内容即可。控制台「能力与拓展」里可以
查看/开关/重载/编辑配置，`extension_manual` 工具就是读的这份说明。

| `system_prompt_folding` | `auto` | 有的模型会吞掉 system 消息（规则全失效）→ 自动探测并把规则搬进用户消息 |
| `task_queue_enabled` | `true` | 任务队列常驻执行器（一切皆任务） |
| `sticker_learning` | `true` | 学习群里的表情包并自主使用 |
| `enable_qzone` / `enable_qq_tools` | `true` | QQ 空间 / QQ 工具自主权 |
| `enable_media_archive` | `true` | 归档群内图片/文件/语音/视频 |
| `agent_max_steps` | `40` | Agent 工具循环最大步数 |
| `subagent_enabled` | `true` | 子 agent（主 agent 可并行派活） |
| `decision_subagent_enabled` | `true` | 决策层需求梳理子 agent |

其余 60+ 项在控制台的「配置」面板里逐条有中文说明。

</details>

> [!TIP]
> **面板保存小坑**：数字字段别留空——AstrBot 保存配置是"全或无"校验，空值会让整次保存被拒。
> 改完不用重启：Sparking 有配置热刷新，面板保存立即生效。

## ❓ 常见问题

<details>
<summary><b>它不回我 / 回得太少</b></summary>

先调 `autonomous_sample_rate`（普通消息采样率），再看冷却项；@ 与私聊不受采样限制。
日志会写明"未采样进入判定""处于冷却"这类原因，按提示调即可。
</details>

<details>
<summary><b>连发几条 @ 它只回了一次</b></summary>

这是**故意的**——连发消息会并成一次回复，像真人一起读完再开口。
想恢复逐条即回，把 `wake_merge_seconds` 设为 0。
</details>

<details>
<summary><b>合并转发 / 聊天记录读不出来</b></summary>

QQ 只在服务端缓存转发资源一小段时间。Sparking 在**消息到达时**就把内容展开存进库，
之后读取优先命中本地记录；只有真的没缓存过才会如实说读不到，不会拿"过期"当借口。
</details>

<details>
<summary><b>换机器了，怎么把它的记忆搬过去</b></summary>

控制台 →「记忆备份」→ 导出并下载，拿到 zip；在新 bot 上同一个面板导入即可（会话、消息、摘要、账本、人物印象、群文化、情绪都会跟着走）。
**导入时要用同一个嵌入模型**：模型不一样就只搬文本与记忆、向量会被跳过（面板会写明原因）。
</details>

<details>
<summary><b>能让它主动加群吗</b></summary>

不能——QQ 协议层没有「主动加群」这个接口（已核对 SnowLuma 动作表与 openapi）。
它能做的是：处理别人发来的**群邀请**与**入群申请**（默认同意），以及查看群资料。
想让它进某个群，请群管理员邀请它，或自己手动拉它进去。
</details>

<details>
<summary><b>它把内部思考 / JSON 发到群里了</b></summary>

发送层做了多重拦截（计划 JSON 泄漏、心声、失控重复）。若仍遇到，请带日志开 Issue——这类问题一律按插件缺陷处理。
</details>

<details>
<summary><b>迁到 Linux 服务器后网页打不开 / 截图里中文是方块 / 图表乱码</b></summary>

先看控制台「概览 → 系统与环境」：缺系统库会直接列出来（照提示 `apt-get install`），中文字体缺失就装 `fonts-noto-cjk`；点「重新检测/安装浏览器环境」会重跑一遍检测并补装。以 root 运行插件时这些依赖会自动装好。
「桌面会话：无」不用管——插件会自动用无头浏览器，`browser_headful` 在没桌面的服务器上会被忽略而不是报错。
</details>

## 🔐 权限与安全（请先读这一节）

装之前请确认你知道它**会做什么**：

- **会执行模型写的代码**：`python_exec`、`program_*`（Flask 小程序）、`scripts/` 拓展都会运行大模型现场生成的 Python，属于沙箱工具执行能力。请只在你自己授权、自己信任的模型与群里启用；不需要就把相关工具关掉/不给权限。
- **会按需自动装依赖**：用到表格、画图、读 PDF、跑小程序、浏览器截图时才 `pip install`（走清华镜像）。不想要自动安装就把 **`auto_install_deps` 关掉**（浏览器环境另受 `browser_auto_install` 控制），关掉后缺依赖会明确提示，由你自己装。
- **会联网**：抓网页、下图片、连你说的 SSH 主机；所有抓取都屏蔽内网/回环地址（SSRF 防护）。
- **数据落在本地**：全部存在 AstrBot 的 `data/plugin_data/astrbot_plugin_long_memory_agent/`，不上传任何地方；`插件控制台 → 运维` 里可以备份或清空。

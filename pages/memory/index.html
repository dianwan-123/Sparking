拓展与技能

          
手写拓展（scripts/）仍是实验性功能：接口可能随版本调整，不建议依赖它做关键流程。

          

        

      


      

        

          
提示词注入 勾选即生效，以【强制规则】追加到系统提示

          
自带预设可以直接启用、也可以改内容；自己的规则点「新增」。
            注入内容写成硬性要求（「每条消息必须 ≤15 字」）效果最好——它们会以
            「违反即视为本轮失败」的强制框架注入，优先级高于普通风格说明。

            你可以直接改解释。

选一个 zip 上传即可：zip 根目录下**每个文件夹是一个群**
            （QQChatExporter V5 导出的 chunked-jsonl，里面有 manifest.json 与 chunks/*.jsonl）。
            每个群都会被学一遍说话风格与群内黑话；不在白名单里的群只写记忆、不接管，
            白名单群还会顺带建群友印象（按活跃度取前几个人）。
            重复导入同一份不会重复计数。
